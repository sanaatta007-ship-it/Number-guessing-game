Number Guessing Game

📖 Overview

The Number Guessing Game is a beginner-friendly JavaScript project that challenges users to guess a randomly generated number. After each guess, the game provides feedback to help the player determine whether the correct number is higher or lower. The objective is to guess the number within the allowed attempts.

This project was created to strengthen my understanding of JavaScript fundamentals and improve my problem-solving skills through hands-on practice.

---

✨ Features

- 🎲 Random number generation
- 💡 Hint after every guess
- ✅ Input validation
- 🔄 Multiple guessing attempts
- 🏆 Win and lose conditions
